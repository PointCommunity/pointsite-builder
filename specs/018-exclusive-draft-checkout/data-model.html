Checkout data model

draft_checkouts

Primary key draft_id; owner actor; active client id; SHA-256 token hash; acquired, last genuine activity, expiry, and update timestamps. Foreign key cascades with draft deletion. Conditional updates provide compare-and-swap semantics.

editor_view_states

Primary key actor; optional active draft; panel; page and element ids; preview viewport and zoom; bounded JSON scroll positions; update timestamp. No document content, dialog state, pending actions, or credentials.

Lifecycle

Expired rows are treated as available and replaced atomically. Archive/delete/revocation makes mutation authority invalid immediately. View state survives checkout expiry but automatic reopening occurs only while the actor still owns a current lease.
