Issue 37 implementation plan

1. Reproduce and isolate

Trace width data from the resize handle through Puck action state, document conversion, the autosave request, repository revision, API response, and reload. Add the smallest failing browser assertion before changing production logic.

2. Make completed resize state authoritative

Change only the boundary that loses or overwrites the final value. Keep transient pointer frames visual-only and submit one final durable action. Verify keyboard and pointer paths independently, then verify delayed acknowledgements and consecutive resizes.

3. Prove persistence

Add schema/checksum plus memory and D1 repository coverage using both headingWidth and bodyWidth. Extend browser coverage across refresh, view changes, checkout release/reacquisition, undo/redo, cancel, Preview, variants, and alignment.

4. Remove the visible Move pill

Remove the visible label node and obsolete styling without removing the semantic full-element move button. Verify pointer movement, keyboard movement, focus-visible styling, resize-handle precedence, editable content, and announcements.

5. Review and release

Run focused checks after each slice, then the complete repository gates and hands-on browser QA. Push a task-owned PR with Refs #37, require exact-head Quality, review, merge, require exact-main Quality, record the prior Cloudflare version, deploy the clean exact main tree, and verify production. Keep Issue #37 open and In Review for PM Showcase testing.

Risks and controls

  • Stale Puck state may overwrite transient or committed width values; regression tests must delay acknowledgements and inspect exact request documents.
  • A full-surface move button can obscure Hero width handles or editable children; stacking, pointer targeting, and keyboard focus receive explicit browser assertions.
  • Repository persistence tests can pass while the client sends the wrong document; evidence is required at both boundaries.
  • No schema migration is expected; stop and obtain PM direction if diagnosis proves one is necessary.
