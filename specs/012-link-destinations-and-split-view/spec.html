Spec: Link destinations, Split View alignment, and safe linked-media insertion

Objective

Make navigation links and every button destination easy to configure as either an internal page or an external website without overcrowding the editor. Expand Split View alignment controls and prevent Linked media insertion from crashing when the draft has no linked-media record.

Assumptions

  • “Links fields” refers to top-level and child navigation entries shown in the supplied screenshot.
  • “All button links” includes hero, heading, Split View, call-to-action, and standalone Button element destinations.
  • Existing persisted href strings remain the storage contract; link type is derived, avoiding a document migration.
  • Draft, hidden, and published pages are all valid internal choices because authors may link pages before publishing.
  • Linked image/video source URLs remain HTTPS-only; the new HTTP allowance applies to navigational external links.

Stack and project structure

React 19, TypeScript 5.9, Puck 0.23, Zod 4, Vitest/Testing Library, and Playwright. Shared link validation belongs in src/site-kit/url-policy.ts; reusable controls belong in src/client/editor/; renderer behavior stays in src/site-kit/registry.tsx and site.css.

Commands

  • Focused tests: npm test -- tests/unit/link-destination-field.test.tsx tests/unit/block-inspector.test.tsx tests/unit/renderer.test.tsx tests/unit/site-document.test.ts
  • Focused browser: PLAYWRIGHT_PORT=4198 npx playwright test tests/e2e/authoring.spec.ts --project=desktop-chromium --grep "link destinations|Linked media|Sections toolbox"
  • Full checks: npm run format:check && npm run typecheck && npm run lint -- --max-warnings=0 && npm run test:coverage && npm run build && PLAYWRIGHT_PORT=4198 npm run test:e2e

Testing strategy

Use RED/GREEN unit tests for HTTP URL policy, internal-page selection, external validation, button reuse, Split View schema/rendering, and missing linked media. Add focused browser coverage for the compact navigation/button controls, new section labels, Split View alignment, and disabled/enabled Linked media insertion.

Boundaries

  • Always preserve existing href values and strict rejection of scripts, credentials, control characters, backslashes, and unsupported schemes.
  • Ask first before changing publishing, authentication, dependencies, or the public PointSite repository.
  • Never expose credentials or permit arbitrary HTML/JavaScript URLs.

Success criteria

  • Navigation and all button destinations expose Internal/External type selection.
  • Internal selection lists page titles and routes; External accepts valid http:// and https:// URLs and visibly rejects missing/unsupported schemes.
  • Section drawer labels read Blank, Two Columns, Three Columns, and Full-Width.
  • Split View text supports Left/Center/Right horizontally and Top/Center/Bottom vertically.
  • Linked media cannot be inserted without an available item and a missing legacy reference renders safely instead of crashing.
