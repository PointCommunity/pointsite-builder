Implementation plan

1. Link contract

Add an HTTP-or-HTTPS navigation URL policy and a reusable, compact destination control that derives type from the existing href. Cover it with focused tests before integrating it.

2. Navigation and buttons

Pass the page catalog into NavigationEditor and every ActionEditor/standalone Button destination. Keep existing href persistence unchanged and validate external drafts before committing them.

3. Split View and labels

Add optional horizontal text alignment, extend vertical alignment to bottom, render both as semantic classes, and rename the four section recipes.

4. Linked media

Disable insertion when no linked-media item exists and render missing legacy references as a safe editor/public placeholder rather than throwing.

5. Verification

Run focused RED/GREEN tests, then formatting, types, lint, coverage, build, and the cross-browser authoring suite on an unoccupied port. Inspect the final diff and preserve production/publishing boundaries.

Risks

  • Partially typed external URLs could invalidate autosave; mitigate with local draft state and commit only valid values.
  • Older internal paths may not match current pages; retain a “current path” option until deliberately changed.
  • Puck insert permissions may be stale after Library changes; configuration rerenders from the current document and browser coverage verifies re-enabling.
