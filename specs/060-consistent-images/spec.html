Issue 60: Consistent People and Cards images

Approved requirements

Issue 60 defines the approved scope. Standard People uses 4:5 contain frames. Vertical Grid retains the leadership value, spacing, name and role presentation, with 4:5 cover frames. Horizontal Grid adds a horizontal variant with 16:9 cover frames and the same grid treatment. Featured retains its intentional first-card span. No existing people selection or biography is removed from saved data.

All seven Cards styles use 16:9 contain frames with a consistent background. Mixed collections reserve matching frames for missing images; entirely text-only collections have no frames. Preserve headings, text, links, alternative text, layout names, colors, spacing and responsive structure. Cards grow for long text, without clipping or overlap; ordinary siblings have equal widths and heights. Images never set grid track widths. Preserve authoring, undo/redo, reload, preview and compatible publication.

Research and reproduction

Baseline source: 11f1b2e8fd7dd202f91109b8babac19c65962029. The shared CardMedia helper and Standard Cards have separate unframed image paths. Standard People has unframed images; leadership has 4:5 CSS and 500 by 625 HTML dimensions but lacks responsive height normalization. Missing Cards images emit no element. Chromium regression at 1280px fails because Standard People computes object-fit: fill instead of contain.

CSS aspect-ratio reserves responsive geometry independently of intrinsic image dimensions. object-fit supplies contain or cover without distortion. Fractional automatic rows equalize cards while accommodating the largest text content. Use existing React, Zod and CSS; add no dependency or measurement code to the product.

Implementation plan

  1. Extend the existing optional People variant enum with horizontal. Keep leadership unchanged; no destructive migration, schema version bump or reauthoring. Exact site-kit blob compatibility prevents publishing new variants to an old renderer.
  2. Route all Cards images through CardMedia with a collection-level reserve flag. Use an inline span placeholder so the existing identity paragraph remains valid HTML. Apply common image and collection classes without replacing layout structures.
  3. Use fixed CSS aspect ratios, explicit width and auto height, contain/cover, and minimum track widths. Equalize image-bearing Cards rows and People rows. Preserve text-only Cards rules and responsive column behavior.
  4. Rename the People option and add Horizontal Grid. Explain frame ratios and cropping in existing authoring guidance.
  5. Verify source, rendering, browser geometry and authoring persistence. Synchronize changed site-kit files using an isolated Staging worktree and its reviewed PR workflow before updating exact contract hashes; preserve its dirty checkout and public Production content.
