Data model: draft preflight and publication lease

publish_preflights

Append-only attempts contain an ID and idempotency key; draft and revision foreign keys; exact revision, candidate, schema, renderer, and renderer-contract identity; observed validation base; status and bounded safe failure code; actor; and timestamps. The latest passed record is current only when revision and renderer-contract identity still match.

publish_jobs additions

lease_expires_at is nullable for historical/completed jobs and required by application logic for active jobs. The active uniqueness index covers both queued and running Staging jobs. A claim transaction expires an overdue active job before inserting or reclaiming exactly one running job.

Compatibility and recovery

The migration is additive except for replacing the partial active-job index. Existing completed jobs and approvals remain unchanged. Existing active rows receive a bounded expiry at migration time. Application rollback remains compatible because the old code ignores added columns and its running-only invariant is stricter than no invariant; remote migration is not destructively reversed.
