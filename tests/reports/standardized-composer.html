Standardized section composer

Verified and deployed September 5, 2026 · America/Chicago

Delivered

SiteDocument schema v2 now represents every page as sections containing nested elements. The editor provides flow and 12-column grid sections, reusable layout presets, element span and alignment controls, categorized drag-and-drop modules, direct canvas selection, and accessible structure controls. Legacy content migrates deterministically into compatibility sections, preserving the current public design.

The Builder defaults to dark mode with a persistent light/dark switch. Builder styles are isolated from both editing and live-preview frames, and phone-sized authoring is replaced by a clear widen-window warning below 720 pixels.
