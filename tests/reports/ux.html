Adversarial UX review

Persona

“Pat,” 61, volunteer church administrator. Comfortable with email and forms, avoids code, has limited patience for publishing jargon, and needs to update a ministry page, preview it on a phone, and safely publish it without risking the live site.

Persona verdict

“I can change the words and pictures without calling a developer, and it clearly tells me the live website is safe. I would use this after someone shows me the first publish.”

Pragmatism filter

Class Observation Disposition
RED — fixed Editor route initially had no obvious page heading/bypass destination. Added draft-name heading and skip link.
RED — fixed At extreme text sizing, the signed-in identity could extend off screen. Made the header and long identity reflow.
RED — fixed Primary preview buttons had unreadable text because of CSS specificity. Corrected component color precedence and added axe regression coverage.
YELLOW First-time publishers may need coaching on “revision,” “checksum,” and “base SHA.” Retain the exact evidence for safety; add contextual help after observing real administrators.
WHITE “I want publishing to skip review and go straight live.” Rejected; staging and exact acceptance are intentional safety controls.

Core journey

Automated browser evidence passes creating/duplicating/archiving a draft, adding and editing modules, updating global design, uploading private media, previewing at 360/768/1280, restoring a revision, recovering conflict/offline work, publishing to staging, verifying exact evidence, and accepting the candidate while production remains locked.

Tickets

No unresolved RED finding remains. One post-deployment observation item remains: test terminology and onboarding with at least one real Point administrator before production enablement.

Limits

The review used the local application with deterministic API fixtures. Live GitHub login, real network latency, and staging deployment are not yet available; screenshots are retained automatically for browser-test failures rather than manufacturing pain-point images after remediation.
