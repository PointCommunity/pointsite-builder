Friendly Builder workspaces

The dark-first Builder now separates Layout, Forms, Library, Preview, History, Settings, and Admin into purpose-built workspaces. Publishing starts from Layout in a clear staging-only overlay. Forms are built field by field, linked images and videos are organized in the Library, revision history is searchable, and audit activity uses GitHub usernames and plain language instead of raw identifiers.
