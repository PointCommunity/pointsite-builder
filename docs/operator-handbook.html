Operator handbook

All commands are run from the named repository. Stop on any failed check; never “fix” staging by writing to production.

Local verification

Builder
npm ci && npm run format:check && npm run typecheck && npm run lint -- --max-warnings=0 && npm run test:coverage && npm run build
Staging
npm ci && npm run check && npm audit --audit-level=high
Expected
Every command exits zero; staging exports all document routes.

Failed staging publish

  1. Record request ID, revision/checksum and displayed base SHA.
  2. If STAGING_BASE_DRIFT appears, refresh; never force the ref.
  3. If CI fails, keep the last passing staging commit and inspect the failed job.
  4. Retry with a new idempotency key only after the cause is fixed.

Stop if the requested path is not one of the two allowlisted content files.

Backup and restore

Export D1 before schema maintenance and retain the staging content commit SHA. Restore a draft through revision history, which creates a new revision. Roll staging back by reverting its content commit through a reviewed staging PR. Never rewrite history.

Credential rotation

  1. Create the replacement credential with the same or narrower scope.
  2. Update the Worker/GitHub environment secret.
  3. Verify identity and one no-op staging-base read.
  4. Revoke the old credential and audit events.

Private keys must never be pasted into issues, logs, D1, source, or client configuration.

Quota response

At 70%, pause nonessential uploads/publishes, review per-actor rates and retention dry-run output, and measure the source of growth. Do not delete current revisions, named revisions, referenced media, or audit evidence.

Production gate

Production is disabled in code and configuration. Before any future preparation, capture accepted staging URL, revision ID, document checksum, renderer version, staging commit, evidence, and current production base SHA. Any drift invalidates approval.

Required exact wording: a new explicit production-preparation approval, followed later by a separate publication approval for that unchanged tuple.
