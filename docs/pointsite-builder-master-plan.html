Controlled staging-first delivery

PointSite Builder

A private, role-based visual authoring system for Point Community Church. Drafts and media stay private; preview and staging use the same validated renderer; production remains a separately authorized exact-candidate action.

Architecture

Private builder

Cloudflare Worker + Access, React/Puck UI, D1 immutable revisions, private R2 media.

Isolated staging

Independent private repository. Builder may atomically update only two allowlisted content files through a staging-only GitHub App.

Public site

Static export only. No Access tokens, database bindings, media credentials, or GitHub credentials enter the bundle.

Delivery gates

G0–G3: Designed and implemented

  • Research, spec, threat model, ADRs, design system
  • Strict document schema and 13 safe modules
  • D1 drafts, autosave, conflicts, history and restore
  • Cloudflare Access JWT and application roles

G4: Staging integration

  • 11 current routes exported from canonical builder content
  • GitHub App candidate uses base-SHA compare-and-swap
  • Production endpoint hard-disabled

G5: External configuration

  • Create D1/R2/Worker and Access policy
  • Create staging-only GitHub App and secrets
  • Deploy, browser-test and accept exact candidate

G6–G7: Production

Out of scope until the accepted candidate is shown and Chris explicitly authorizes production preparation, then publication. No earlier approval carries forward.

Acceptance

  1. Admins authenticate through Cloudflare Access; application roles are rechecked on every request.
  2. Editors create, duplicate, autosave, preview, compare and restore drafts without overwriting newer work.
  3. All modules have keyboard/button operations as equivalents to drag.
  4. Staging renders the same schema/renderer and passes route, asset, security, accessibility and build checks.
  5. Publisher sees exact revision, checksum and base SHA before staging publication.
  6. No production repository write occurs before exact-candidate authorization.

Cost posture

Free-first: static public delivery, Workers request allowance, D1/R2 free quotas, and GitHub private repositories. Capacity warnings begin at 70%; paid plans are considered only after measured use warrants them.
